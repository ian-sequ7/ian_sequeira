# Ian Sequeira's Portfolio

Personal portfolio site at [ian-sequ7.github.io/ian_sequeira](https://ian-sequ7.github.io/ian_sequeira/). Statistics & Data Science researcher at UC Santa Barbara — sequential inference, multi-agent AI reliability, biostatistics.

## Stack

- Vanilla HTML5, CSS3 (custom properties), and JavaScript — no framework
- Editorial-scholar design system: DM Serif Display + Inter, burgundy accent (`#7A1F2E`)
- [Font Awesome](https://fontawesome.com/) (kit-loaded) for icons
- [Formspree](https://formspree.io/) for the contact form
- Hosted on GitHub Pages

## Structure

- `index.html` — homepage (hero, about, projects, life, contact)
- `fintel.html` — Fintel project subpage
- `research-advisor-finder.html` — Research Advisor Finder subpage
- `style.css` — design system and component styles
- `script.js` — nav toggle, time-aware greeting, smooth-scroll
- `sitemap.xml`, `robots.txt` — SEO
- `images/` — photography and project thumbnails

## Features

- Responsive layout (mobile, tablet, desktop)
- Accessible navigation (skip-link, `aria-expanded` toggle, `prefers-reduced-motion` support)
- JSON-LD structured data + Open Graph / Twitter Card metadata
- Lazy-loaded images
- Project subpages with embedded demo videos
